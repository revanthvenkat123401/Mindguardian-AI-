About MindGuardian AI

The vision behind the hackathon project

Problem Statement

Build an On-Device Small Language Model system that estimates burnout risk using webcam micro-expressions and microphone voice characteristics while keeping all user data completely on the local machine without sending anything to the cloud.

Architecture

The system utilizes a multi-modal approach. Vision and Audio Engines process local streams. The Signal Processor and Feature Fusion layers prepare the data for Risk Estimation. A Prompt Generator contextualizes the risk for a Local SLM, powering the Decision Engine.

Tech Stack

  • Frontend: HTML5, CSS3, Vanilla JavaScript (ES6)
  • Design: CSS Variables, Glassmorphism, Linear/Apple Aesthetic
  • No-Build: Runs perfectly offline without NPM, React, or Tailwind.

Privacy First

In an era of ubiquitous cloud computing, physiological data is highly sensitive. MindGuardian AI runs 100% offline. No internet connection is required, ensuring complete data sovereignty and privacy.

Future Scope

Integration with wearable devices (smartwatches), advanced biometric sensing, more specialized localized models for specific professions, and cross-platform native applications.
